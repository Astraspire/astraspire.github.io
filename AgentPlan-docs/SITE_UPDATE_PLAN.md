| **Build output (what gets deployed)** | `my-app/dist/` | Generated by `npm run build`. |
| **Live/deployed site** | root `index.html` + `assets/` | References a specific **hashed** JS file (`index-Cn5uXNSK.js`). |

**Deploy workflow note:** `index.html` (root) and `assets/` are the *built* version. Every time we change `App.jsx`, we run `npm run build` in `my-app/`, which regenerates `dist/`. The root `index.html` + `assets/` are the deployed copy that GitHub Pages serves. Any rebuild changes the hashed asset filenames, so both `dist/` and the root `assets/` + `index.html` need to stay in sync.
